# Видеодемонстрация работы приложения (практическая работа №3)

Требования: запись экрана смартфона/эмулятора с запущенным приложением, не более **5 минут** и не более **25 МБ**
(если видео прикладывается в архив). Если файл больше — загрузить на облачное хранилище и дать ссылку.

## Сценарий записи (≈ 2–3 минуты)

1. **Запуск.** Открыть приложение, показать нижнее меню: Сегодня, Активность, Дневник, Карта, Профиль.
2. **Create (создание).** Вкладка «Дневник» → кнопка «+» → выбрать настроение, написать текст →
   «Сохранить». Появляется сообщение «Запись сохранена», заметка видна в списке.
3. **Проверка пустого поля.** Нажать «+» → «Сохранить» без текста → ошибка «Введите текст заметки».
4. **Read (чтение).** Полностью закрыть приложение (смахнуть в списке запущенных) и открыть снова →
   заметка осталась на месте (данные хранятся в базе SQLite).
5. **Update (изменение).** Нажать на заметку → изменить текст и настроение → «Сохранить» → в списке новый текст.
6. **Delete (удаление).** Нажать на заметку → «Удалить» → заметка исчезает из списка.
7. **Остальной функционал (по желанию).** «Сегодня»: «+500 шагов», «+250 мл» — числа и балл здоровья
   меняются; «Погода»; «Карта»; переключатель языка EN | RU.

## Как записать видео

**Вариант 1 — встроенная запись экрана телефона** (шторка уведомлений → «Запись экрана»).

**Вариант 2 — через adb** (телефон подключён по USB, отладка включена). Запись идёт до 3 минут:

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb shell screenrecord --time-limit 170 --bit-rate 1000000 /sdcard/demo.mp4
# запись остановится сама через 170 секунд; можно остановить раньше сочетанием Ctrl+C
Start-Sleep -Seconds 2
& $adb pull /sdcard/demo.mp4 "$env:USERPROFILE\Desktop\demo.mp4"
"{0:N1} МБ" -f ((Get-Item "$env:USERPROFILE\Desktop\demo.mp4").Length / 1MB)
```

Последняя команда показывает размер файла. Если он больше 25 МБ, видео можно уменьшить (нужен ffmpeg:
`winget install Gyan.FFmpeg`, затем перезапустить PowerShell):

```powershell
ffmpeg -i "$env:USERPROFILE\Desktop\demo.mp4" -vf scale=-2:720 -b:v 600k -an "$env:USERPROFILE\Desktop\demo_small.mp4"
```

## Проверка CRUD-методов тестами (по желанию, можно показать в видео)

С подключённым телефоном или запущенным эмулятором:

```powershell
.\gradlew.bat --no-daemon --console=plain connectedDebugAndroidTest
```

Тест `NotesDbTest` проверяет создание, чтение, изменение и удаление записей в базе данных.
