# Средства обеспечения безопасности — Wellness Tracker

## 1. Принципы

- Минимум данных: нет аккаунта, нет рекламы, нет аналитики и трекеров.
- Данные о здоровье хранятся только на телефоне, в закрытой памяти приложения.
- Минимум разрешений: приложение не просит доступ к геопозиции, контактам, камере, микрофону и памяти.
- Весь сетевой трафик идёт только по HTTPS.

## 2. Средства защиты в приложении

| Угроза | Средство защиты | Где в проекте |
|---|---|---|
| Доступ других приложений к данным | Данные лежат в закрытом хранилище приложения (SharedPreferences и SQLite) в песочнице Android; наружу открыт только экран запуска, служба шагов не экспортируется, своих content provider и FileProvider нет | AndroidManifest.xml |
| Утечка через резервные копии | Резервное копирование отключено (allowBackup=false); профиль, шаги и заметки исключены из облачной копии и переноса на другое устройство | AndroidManifest.xml, res/xml/backup_rules.xml, data_extraction_rules.xml |
| Перехват сетевого трафика | Открытый HTTP запрещён (usesCleartextTraffic=false и network_security_config); доверяются только системные сертификаты; все API работают по HTTPS | res/xml/network_security_config.xml, network/ |
| SQL-инъекции | Запросы к базе данных параметризованы: значения передаются через ContentValues и аргументы selectionArgs, текст заметки никогда не вставляется в SQL | data/NotesDb.kt |
| Некорректный ввод | Проверка диапазонов в профиле (возраст, рост, вес, цель), запрет пустой заметки, безопасный разбор чисел, кодирование параметров запроса (URLEncoder), в приложении нет WebView и выполнения чужого кода | ProfileFragment.kt, NoteEditorFragment.kt, network/ |
| Лишние права | Запрашиваются только нужные права: физическая активность и уведомления (по запросу, с возможностью отказа) и интернет. Без разрешения на активность шаги вводятся вручную | AndroidManifest.xml, MainActivity.kt |
| Подмена намерений (Intent) | PendingIntent создаётся с флагом FLAG_IMMUTABLE; для карт используется неявное намерение geo: без передачи личных данных, кроме названия места | StepCounterService.kt, MapFragment.kt |
| Утечка секретов | В коде нет ключей и паролей: используются открытые API без ключей. Файлы local.properties и ключ подписи не попадают в репозиторий (.gitignore) | .gitignore |
| Хранение данных после использования | Кнопка «Удалить все мои данные» в профиле стирает профиль, шаги, воду, сон и все заметки с телефона после подтверждения | ProfileFragment.kt, MainViewModel.kt |
| Подмена приложения | Release-сборка подписывается ключом разработчика; ключ хранится вне репозитория; в магазинах доступна подпись приложения магазином | Раздел «Выпуск приложения» |

## 3. Какие данные хранятся и куда отправляются

| Данные | Где хранятся | Передаются ли в сеть |
|---|---|---|
| Профиль (имя, возраст, рост, вес, город) | На телефоне | Только название города — сервису геокодирования Open-Meteo |
| Шаги, вода, сон | На телефоне | Нет |
| Заметки дневника | На телефоне, база SQLite | Нет |
| Погода и места рядом | Не хранятся (кратко кэшируются в памяти) | Отправляются координаты города в Open-Meteo и Overpass API |

Идентификаторы пользователя, рекламный идентификатор и данные об устройстве приложение не собирает и не отправляет.

## 4. Разрешения приложения

| Разрешение | Зачем | Когда запрашивается |
|---|---|---|
| INTERNET, ACCESS_NETWORK_STATE | Карта, погода, поиск мест | При установке (не требует действий пользователя) |
| ACTIVITY_RECOGNITION | Автоматический подсчёт шагов | При первом запуске, можно отказаться |
| POST_NOTIFICATIONS | Показ значка работающей службы подсчёта шагов | При первом запуске (Android 13 и новее), можно отказаться |
| FOREGROUND_SERVICE, FOREGROUND_SERVICE_HEALTH | Подсчёт шагов при закрытом приложении | При установке |

## 5. Выпуск приложения: подпись и защита кода

- Создать ключ подписи (keytool) и хранить его в надёжном месте вне репозитория, с резервной копией.
- Подписать release-сборку и пакет AAB; использовать подпись приложения магазином (Play App Signing).
- Включить сжатие и обфускацию R8 для release-версии и проверить её работу на телефоне.
- Release-версия не должна быть отладочной (debuggable выключен по умолчанию).

## 6. Ограничения и план усиления

Данные в базе и настройках не шифруются отдельно: защиту обеспечивают песочница Android и шифрование памяти телефона. Блокировки по PIN-коду или отпечатку пальца в приложении нет. Планы: шифрование базы (SQLCipher) и настроек (EncryptedSharedPreferences), блокировка входа по биометрии, проверка зависимостей на уязвимости, регулярное обновление библиотек и статический анализ (Android Lint).
